# Página de Perfil Interativa

Projeto desenvolvido durante meus estudos em desenvolvimento web, com foco na criação de uma página de perfil moderna e interativa.

## 🚀 Sobre o projeto

Esta aplicação utiliza **HTML, CSS e JavaScript** para criar uma experiência de usuário mais dinâmica e personalizada.

Entre os recursos desenvolvidos estão:

* Manipulação do DOM com JavaScript
* Alteração dinâmica de conteúdo
* Tema claro e escuro
* Interações com botões e eventos
* Efeito de interação com a foto de perfil
* Relógio em tempo real
* Primeiro projeto utilizando Node.js
* Inicialização e gerenciamento de projeto com npm
* Utilização de pacotes externos

## 🛠️ Tecnologias

**HTML5 • CSS3 • JavaScript • Node.js • npm**

## 🎯 Objetivo

Este projeto faz parte da minha jornada de aprendizado em programação e desenvolvimento web. Estou buscando evoluir continuamente minhas habilidades, transformar conhecimentos em projetos práticos e construir um portfólio cada vez mais profissional.
